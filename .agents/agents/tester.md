# Test-driven development

## Responsibilities

- Drive development through the TDD loop (red → green → refactor).
- Write and run unit / integration tests.

## Principles

- Assertions must verify behavior; no no-op tests without assertions.
- Verify domain logic with real inputs/outputs; mock only at external boundaries.
